# 余烬信使 · EMBER COURIER

> 长夜吞没了城市。总有一些光，值得送达。

一款从零创作的单人俯视角轻度生存冒险。你是背着邮包的猫头鹰 **烛羽**，穿过三片沉睡的街区，点亮九座灯塔，击败守夜者，把黎明送回城市。

**[在线试玩](https://ember-courier-game1.dazzlingmodel.chatgpt.site)** · [游戏设计](docs/DESIGN.md) · [验证记录](docs/QA.md) · [部署说明](docs/DEPLOYMENT.md)

网页版现已公开访问；Android APK 与完整网页 ZIP 从 [GitHub Releases](https://github.com/AureliusWu/Game1/releases) 下载。Android 构建说明见 [ANDROID.md](docs/ANDROID.md)。仓库里的静态游戏可以独立托管，不依赖 ChatGPT、任何 API 或在线服务。

## 玩什么

- 三章街区：沉灯街、雨眠庭、无晓钟楼；完整开局、成长、首领战与结局。
- 走近火种自动拾取并回血；携带 4 枚火种靠近灯塔约 1.25 秒，自动点亮。
- 灯塔周围恢复生命、驱散普通影兽并抵挡敌方光球。守夜者能够进入灯塔范围，需要继续躲避。
- 自动光弹负责瞄准；主动光环击退近敌；冲刺短暂无敌。
- 每章点亮三座灯塔后，走进右侧金色拱门。街区之间从随机的三项强化中选择一项。
- 漫游 / 标准 / 长夜三档难度，单局约 3–8 分钟；熟练玩家可更快。
- 原创 Canvas 矢量风格画面、猫头鹰角色、合成氛围音乐与音效。
- 支持键鼠、触屏、横竖屏；自动存档、最高分与旅途统计；PWA 离线缓存。

## 「暮色百事」系统

一份让战斗、送信与长期成长互相影响的扩展，原有三章与最终结局完整保留。

| 系统 | 实际玩法 |
| --- | --- |
| 装备与背包 | 12 件装备、提灯/披羽/邮包三槽位；伤害、移速、减伤、暴击等即时生效 |
| 套装与锻造 | 远行邮差、守灯人、曙光回声三套；二/三件套；两次锻造与非穿戴装备拆解 |
| 剧情与投递 | 三位居民、每人两条选择；消耗真实火种的帮助会提高信任；在灯塔旁投递 |
| 结局与档案 | 黎明签收、回信成河、人间灯火三种结局；永久信件与结局收藏 |
| 成就 | 20 项成就，解锁即奖励邮票，重复读取和结算不重复发奖 |
| 邮局成长 | 五门永久课程，每门三级；下一局生效；发现过的装备可挑一件作为启程藏品 |
| 经济与商店 | 星砂来自战斗、点灯与探索；购买装备、热茶与便携补给；库存与费用真实扣除 |
| 奇遇与精英 | 每章一个奇遇，共三种；资源、生命与战斗风险的选择；精英击败后才掉落奖励 |
| 等级与连击 | 单局经验和八级成长；五秒内连续击败形成连击与额外得分 |
| 邮局委托 | 六种可选目标：点灯、驱影、投递、开箱、限时、不用补给；结算奖励邮票 |
| 每日航线 | 北京时间日期种子、标准难度、加急委托；当天首次通关额外三枚邮票 |
| 图鉴与存档 | 装备、影兽、居民来信永久记录；旧版运行中存档自动迁移至 schema 2 |

靠近居民、失物箱、商店或奇遇会出现互动按钮。打开背包、商店和剧情时暂停游戏。剧情支线可以跳过，直接送达仍有独立结局。

## 操作

| 动作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | WASD / 方向键 / 点击地面 | 左下摇杆 / 点击地面 |
| 冲刺 | 空格 | 右下冲刺键 |
| 光环 | E | 右下光环键 |
| 互动 | F | 情境互动按钮 |
| 背包与手札 | J | 右上邮包键 |
| 补给 | H | 补给杯按钮 |
| 暂停 | P / Esc | 右上暂停键 |
| 声音 | M / 菜单设置 | 菜单设置 |

每 8 秒自动存档；暂停、切到后台、换装交易或退出页面时也会保存。永久课程与收藏单独保存；旧版运行中存档保留原地图、生命、火种、强化与进度。刷新后选择「继续上次旅途」。开启新旅途会替换上一份未完成存档。胜负结算后计入总记录。

## 本地运行

需要 Node.js 22+。没有依赖安装步骤。

```bash
npm run dev
```

打开终端给出的地址（默认 `http://localhost:5173`）。直接双击 HTML 的 `file://` 模式不支持 ES 模块，请使用本地服务器。

```bash
npm test
npm run check
```

## 代码

```text
dist/
  core.mjs              确定性游戏模拟、关卡、技能、战斗与存档校验
  render.mjs            Canvas 原创画面、角色、镜头、粒子与小地图
  app.mjs               UI、键鼠/触屏输入、存储和暂停生命周期
  audio.mjs             Web Audio 合成音乐与音效
  content.mjs           装备、剧情、奇遇、委托与成就的原创数据
  systems.mjs           装备、交易、投递、等级与任务规则
  progress.mjs          永久成长、成就与幂等结算
  hub.mjs               背包、手札、邮局、成就、图鉴与互动界面
  index.html, style.css 响应式菜单、HUD、手册、强化与结算
  sw.js                 完整静态壳离线缓存
  manifest.webmanifest  可安装的 PWA 元数据
scripts/                无依赖开发服务器和静态检查
tests/                  单元、模拟与真实规则通关测试
docs/                   设计、部署与验证记录
```

GitHub Actions 在每次 main 推送和 PR 时执行测试、检查资源完整性，并生成可下载的完整 Web 版。另附可手动启用的 GitHub Pages 镜像工作流。
