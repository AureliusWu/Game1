## 无尽夜航

- 四种起始武器、八种被动、四种组合进化，最多三武器与四被动。每次升级三选一，构筑会改变实际攻击与主动技能联动。
- 八件奇物、五类路线、三首领模式与三种天气，风险和奖励由你取舍。
- 无尽层数，每五层首领；可随时保存，在清场后主动封存结算。初始两次重抽，商店和首领可以补充。
- 自动光弹、主动冲刺与光环、可打断预警、有限补给。灯塔消耗五火种回复 20% 生命，没有持续回血安全区。

## 剧情送信

- 三章街区：沉灯街、雨眠庭、无晓钟楼；完整开局、成长、首领战与结局。
- 走近火种自动拾取并回血；携带 4 枚火种靠近灯塔约 1.25 秒，自动点亮。
- 灯塔周围恢复生命、驱散普通影兽并抵挡敌方光球。守夜者能够进入灯塔范围，需要继续躲避。
- 自动光弹负责瞄准；主动光环击退近敌；冲刺短暂无敌。
- 每章点亮三座灯塔后，走进右侧金色拱门。第一章第二盏灯与两次换章时，从 12 项强化池中选择三次。
- 漫游 / 标准 / 长夜三档难度，单局约 3–8 分钟；熟练玩家可更快。
- 原创 Canvas 矢量风格画面、猫头鹰角色、合成氛围音乐与音效。
- 支持键鼠、触屏，固定横屏游玩；自动存档、最高分与旅途统计；PWA 离线缓存。

## 操作

| 动作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | WASD / 方向键 / 点击地面 | 左下摇杆 / 点击地面 |
| 冲刺 | 空格 | 右下冲刺键 |
| 光环 | E | 右下光环键 |
| 互动 | F | 情境互动按钮 |
| 构筑 / 剧情背包 | J | 右上邮包键 |
| 补给 | H | 补给杯按钮 |
| 暂停 | P / Esc | 右上暂停键 |
| 选卡 | 1 / 2 / 3 或点击 | 点击卡牌 |
| 声音 | M / 菜单设置 | 菜单设置 |

每 8 秒自动存档；暂停、切到后台、换装交易或退出页面时也会保存。永久课程与收藏单独保存；旧版运行中存档保留原地图、生命、火种、强化与进度。刷新后选择「继续上次旅途」。开启新旅途会替换上一份未完成存档。胜负结算后计入总记录。

## 本地运行

需要 Node.js 22+。没有依赖安装步骤。

```bash
npm run dev
```

打开终端给出的地址（默认 `http://localhost:5173`）。直接双击 HTML 的 `file://` 模式不支持 ES 模块，请使用本地服务器。

```bash
npm test
npm run check
```
