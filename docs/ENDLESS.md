# 无尽夜航规则与维护

`endless.mjs` 无 DOM 依赖，保存状态 `s.endless.version=1`，复用 schema 3。`createGame()` 默认剧情以保持已有调用方；网页默认 `mode=endless`。每日航线强制使用既有公平剧情规则。

## 循环

开始时选一件武器。击杀落下经验微光，真实靠近拾取；清场时吸取剩余经验。经验阈值为 `18n+4n²`（n = 等级−1）。升级与每次清场提供强化选择，满级卡与超出槽位的新卡不会出现。最多 3 武器 / 4 被动，各五级；武器五级与对应被动二级同时满足时自动进化。已满构筑继续获得伤害淬炼、恢复或补给选择。

一层的敌群有固定生成预算，同时最多 30 敌人；必须击败全部已生成与待生成敌人才能清场。每五层生成一名首领。清场奖励按 `clearedRoom` 一次结算，顺序为待领取强化 → 首领/回廊奇物 → 下一层路线。没有终点层数。仅在清场路线界面可封存结算；途中可保存续玩，死亡正常结算。

每层独立生成地图、天气、战斗波次；选卡随机流独立保存，不受渲染影响。初始有两次重抽，击败首领返还一次，最多三次；路线界面不能重抽。清场商店可以各买一次热茶、药剂与重抽，库存随房间存档。路线休整与商店都真实扣费。

## 组合

| 武器五级 | 被动二级 | 进化 |
| --- | --- | --- |
| 爆焰行灯 | 急件封蜡 | 不灭凤凰，光弹额外目标，爆炸留下火海 |
| 霜降邮戳 | 静夜镜片 | 永冬回信，冰环冻结，寒霜敌人额外承受光弹伤害 |
| 回旋护羽 | 顺风羽签 | 千羽风暴，双层羽刃与光环羽暴 |
| 连锁雷笺 | 引光罗盘 | 万象雷网，远距离跳雷与终点雷爆 |

奇物有八件，每件本局只收一次。玻璃灯心降低最大生命同时提高伤害；第二次黎明只可复起一次。天气从第四层开始出现，雷雨预警固定锁定脚下后才判伤，疾风加强敌人移速并增加拾取范围，烬雪提高敌人生命并加强拾光恢复。

无尽灯塔每座消耗五火种，停留 0.65 秒后回复 20% 最大生命并震伤近敌。没有持续安全区、驱敌或挡弹效果。清场回复 10% 最大生命，失物磁石另加 8。升级和重抽不无条件回满生命。

## 生命周期

所有选卡类型共用 `phase=upgrade` 冻结时钟与输入，`endless.choice` 区分 skill/relic/route。选择存储在 offered，不在展示或恢复时重掷。旧 `v12.choiceKind` 不参与无尽草稿，但其其余校验仍执行，之后验证独立无尽状态。战斗对象/技能冷却/火径/天气预警/商店消费均持久化；粒子与伤害数字不影响模拟。

无尽最高已清层、分数、首领累计和局数在原 profile 键增加可选字段；旧 profile 缺字段补零。无尽主动封存使用 won 触发结算 UI，但不增加剧情 wins 或解锁故事结局。结算邮票为 `min(20, 清场层数+首领数×2)`，另计真实完成委托和一次性成就，用原 journey ledger 防重。

验证命令：`npm test`、`npm run check`、`node scripts/endless-audit.mjs`。完整策略不得直接更改模拟实体或奖励。
