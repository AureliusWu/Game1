# v1.5.1 小屏视觉收尾

v1.5.0 的 152 项规则测试和 144 个真实动作实验见 [原验证记录](QA_v1.5.0.md)。v1.5.1 只修改选择面板 CSS、同步版本与离线缓存；core.mjs 只有 VERSION 字符串变化，所有模拟规则、敌人 AI、奖励与武器数值保持逐字相同。因此沿用原 144 个样本，不冒充重新实验。

真实 Android 320×640 与 640×320 截图发现成就浮层覆盖角色、竖屏底部按钮裁切，修订为选卡期间隐藏浮层、可收缩卡牌区域与保留底部操作。新增原生几何断言确保所有可见底部按钮完整处于面板内，继续验证真实击杀触发选卡、暂缓、剩余时间保存和自动选择。

截图采集在 WebView 视觉状态就绪及提交帧后执行；测试机预先处理首次全屏说明，防止截到系统覆盖层。截图在应用卸载后保留，归档前校验 PNG 格式、尺寸与横竖方向。既有 v1.5.0 发布附件保持不变。

最终发布与视觉证据写入 releases/v1.5.1-verification.json，只有实际成功后更新为完成。
