# v1.4.0 疾焰连击：战斗研究与实现

目标是让「移动切入 → 击杀蓄能 → 爆发清场 → 拾光选卡 → 再入敌潮」形成可辨认的节奏。

## 依据与设计判断

- Lin 等人的 [Impact Feel 研究（2022）](https://arxiv.org/abs/2208.06155) 提出 19 项战斗反馈特征，并从玩家评论与游戏案例中发现停顿、声音一致性与镜头设计可能影响命中感。它提供设计线索，不能证明某个数值会让本游戏更好玩。
- 任天堂的 [Vampire Survivors 开发者访谈](https://www.nintendo.com/jp/topics/article/3f3d9c44-6cc5-4197-a31b-1397f229c03b) 谈到不同武器、升级选择、惊喜和奖励视听表现如何保持每局的新鲜感。这里保留用户要求的无尽层数与自主封存，采用主动技能与构筑联动。
- 源码与基准实验发现：普通敌人补充间隔较长，冲刺没有直接进攻收益，原连击主要增加分数；多目标伤害缺少统一的命中表现，较高等级急件封蜡会撞上基础射速下限。

## 实施

| 问题 | 已实施行为 | 约束 |
| --- | --- | --- |
| 操作回报弱 | 冲刺沿真实路径切敌、光环清近身敌弹 | 每次冲刺对一敌只伤一次，遮挡与出生预警有效 |
| 连杀缺乏高潮 | 击杀充能，自动 6 秒破晓超载；刷新一次技能、加快武器 65% | 爆发期间停止充能，不免费回血或提供额外无敌 |
| 敌潮松散 | 更近的预警出生、更多普通敌人、更短补充间隔；低存量时及时补充 | 固定房间预算、同时 30 敌人、首领与重装保留耐久 |
| 命中看不清 | 90ms 亮色、受击变形、描边、伤害合并、冲刺光痕、分层合成音 | 碰撞不随变形改变；降低动态效果可关闭闪亮与震动 |
| 成长信息不清 | 武器卡展示基础伤害、范围或攻击数量；就绪进化高亮 | 实际效果仍受已有被动影响，卡片明确标注基础值 |
| 清场缺少表现目标 | 显示本层用时，无伤额外 +6 星砂 / 200 分 | 奖励同清场状态一起记账，读档不重发 |
| 绕路折返卡住 | 规划后沿最远可见路径点继续追击 | 保留半径与障碍检查；慢速结界者种子 1301 实际旅途回归 |

## 验证方法

同种子节奏实验使用完全相同的动作策略与 12 个组合（3 种子 × 4 起手），模拟真实移动、技能、拾取、伤害和存档恢复。首次击杀、首次选卡、每分钟击杀、超过 3 秒未击杀的占比，均来自模拟时钟；选卡思考时间不包含在内。

基准来自 v1.3 正式源码，结果见 `balance/v1.3.0-combat-pacing.json`；新结果见 `balance/v1.4.0-combat-pacing.json`。144 次跨难度、路线和站桩实验在对应 CSV / JSON 保存。数据用于比较节奏与查找卡住，不代表人类胜率、主观爽感或留存。

旧版剧情与 v1.3 真实存档兼容重放、完整送信结局、手机双指/旋转与离线发行检查一并执行。实际手机的长期耗电与操控偏好需要真实游玩反馈。
