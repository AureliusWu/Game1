## 解读边界

策略机器人知道完整地图，能直接读取招式提示，模拟不包含阅读、渲染与人类反应。通关比例不代表玩家胜率；浓雾的视觉影响需要实际界面操作，不能由全图机器人判断。UI 中的 3–8 分钟是短局体验目标，熟练策略的模拟时间更短。

实体 Android/iOS 的长期功耗、长时音频及厂商 WebView 差异未验证。Android 检查包含 Activity 重开，不宣称完成真实进程强杀恢复测试。
