# v1.5.0 战场回响验证

## 范围与规则

152 项测试覆盖既有规则、真实剧情旅途与旧存档，新增 16 项选择计时、暂停、背景遮挡、重抽、自动路线合法性、真实飞弹、锁定预警、首领阶段、结界破绽、连斩与 v1.4 真实存档重放。新计时可保存，真实模拟仍在选择期间冻结；超时选择走同一份合法选择事务。

运行静态检查：23 个运行文件、145 个唯一 UI ID，所有文件进入离线缓存，版本一致。最终模拟数据在 balance/v1.5.0-endless-summary.json / CSV，动作策略保持真实移动、拾取、技能、伤害与存档恢复，不编辑角色数值或房间完成标记。144 个样本用于检查规则与卡住，不代表人类胜率。

桌面浏览器实际观察：底部选择面板、角色上移保留战场、P 暂缓；不点击卡牌时自动将爆焰行灯从 Lv.1 升至 Lv.2，待选次数从 4 减为 3，显示下一份倒计时。实际清怪与拾光触发选择，没有注入模拟状态。

## Android 门禁

保留 4 项离线、返回、存档、双指、旋转、真实选卡验收。新增第 5 项真实操作：自然清怪打开紧凑面板，验证非模态、纵向少于 45% 视口、横向少于 49% 视口、无页面溢出；暂缓不走表，保存恢复相同剩余时间，再继续计时并实际自动选卡。保存真实纵向/横向截图到 CI 归档，未注入战斗状态。

最终发布结果、不可变源提交、APK 签名与资源核对、网页保存与部署 ID 写入 releases/v1.5.0-verification.json。
