# 余烬信使 v1.2.0 更新方案 · 夜路有选择

制定日期：2026-11-06。当前正式版：v1.1.1，网页与 Android 已发布。

本次交付是更新方案、可复跑的分析工具和基线数据。线上继续使用 v1.1.1；功能开发按下述批次推进。

## 1. 版本目标

让玩家能通过赶路、守灯、光环爆发三种方式完成旅途，每章都有值得权衡的路线与资源选择，长夜提供更强的战斗要求。

保留烛羽、三章、九座灯塔、三种有限结局、自动瞄准和现有触屏按键。维持短局体验：首次阅读和探索的设计目标为 4–8 分钟，熟练玩家可以更快；此目标需要实际试玩验证，不通过增加等待时间实现。

## 2. 当前基线与问题

运行时基线对应 v1.1.1；调查开始时 main 为 `90946be9072324d279399863f4bdffdefc863d73`。数据来自实际规则模拟，不涉及真实玩家数据。

完成 360 次常规旅途对照、30 次驻灯首领旅途、30 次驻灯 120 秒探针，共 420 次实验。常规旅途覆盖新档/满课程且携带折光黎明灯的预设、三档难度、直送/三封信/分享灯火路线。常规旅途 359 次到达结局，1 次在 1200 秒上限时仍未结束；驻灯首领旅途 26 次到达结局、4 次未结束。未结束样本不是死亡，不计为通关。

**这些机器人知道地图位置并使用寻路，模拟时长不含阅读和菜单决策；它们的成功比例不是玩家胜率。** 结算血量包含各种恢复效果，也不能单独代表战斗压力。

| 发现 | 现有证据 | 更新意义 |
| --- | --- | --- |
| 安全刷取过强 | 新档点亮第一座灯后驻留 120 秒，仅自动光弹、无冲刺/光环/补给：标准额外星砂中位数 110、经验 165；长夜为 132/198，30 个探针均无额外受击且结束时满血 | 巡逻数量与可领取资源分开配置，限制无限刷取及高难刷取优势 |
| 首领缺少主动应对要求 | 新档长夜驻灯首领策略 10/10 个样本到达结局，整局不使用光环、冲刺或补给 | 增加清晰预警、位置变化和可打断招式，使走位/技能有作用 |
| 经济选择不够紧 | 新档标准三封信路线已购买 3 次、锻造中位数 6 次，结算仍剩 222.5 星砂；总收入中位数 366 | 同时检查收入、投入时点与可购买的有效选项，建立花钱的取舍 |
| 新旧档起点差距明显 | 新档面板期望单目标光弹 DPS 20；满课程+稀有启程藏品为 34.83，约高 74%；初始补给 1→4 | 故事旅途保留成长，新增统一预设的公平挑战航线 |
| 内容重玩变化有限 | 三章灯塔/障碍布局固定，居民、箱子、商店、奇遇设施的坐标固定；主要变化集中在火种、掉落和刷怪 | 用已校验的街区模板和可选支路增加路线变化 |
| 构筑的行为区别不足 | 当前三套装主要提供属性、金币或冷却；每局通常只有两次跨章强化选择 | 给三件套加入不同触发机制，并增加一次局内构筑节点 |
| 存在追击停滞候选 | 标准直送种子 1004 中，玩家停在灯塔，守夜者在远处障碍附近反复小幅移动，生命仍为 500；驻灯首领另有 4 个类似超时样本 | 优先分离敌人追击问题和机器人选点问题，补恢复路径与诊断 |

停滞记录尚不能证明玩家被软锁；玩家可能通过接近或换位继续战斗。处理时同时修复敌人路径恢复与测试策略的主动接敌逻辑，保留原始失败样本。

另有两处说明应同步修正：所有跨章强化都会回满生命，灯芯文案应准确表达它的独特收益；双星邮戳当前还隐藏了每层 -0.1 秒射击间隔，应明确展示或在重新设计时移除这项隐含优势。

### R1：让难度、资源与战斗形成约束

**A. 追击恢复。** 敌人持续约 1 秒无法向目标推进时，触发一次低频路径重算。缓存路径并限制每帧求路次数；大型首领按完整半径规划。机器人在首领长期不接近且超出射程时会主动换位，避免把测试策略僵持误判为游戏不可通关。

**B. 巡逻与经济预算。** 进入街区时生成有限巡逻及其奖励预算；精英、首领、点灯和投递分别有明确奖励。长夜增加压迫、组合和时机要求，常规巡逻的整章可领取资源与标准同档。预算耗尽后不再无限补充可刷资源的巡逻，剩余流程仍可正常完成。

保留清理巡逻后从容探索的玩法。每个奖励在生成时确定、死亡时领取一次；存档恢复、重复交互和跨章不得重置已领取预算。套装额外星砂、连击计分和可能的重复掉落都纳入同一有限奖励来源，避免通过附加奖励绕开预算。十五只影兽委托必须在可达的巡逻/精英组合中完成。

**C. 灯塔继续提供归处。** 维持点灯奖励和脱战休整；标准/长夜战斗中降低持续恢复。战斗判定依据附近威胁或近期受击，避免仅靠短暂无伤间隔反复触发高回复。漫游保留更宽松的恢复规则。

**D. 首领增加可读的应对。** 保留当前追击与环形光球，加入两个有提示的阶段：

- 约 70% 生命：标记一处已点亮灯塔，预警后短暂压制该处恢复；灯塔仍算已点亮，不回退主线进度。玩家可换到另一盏灯或利用空档进攻。
- 约 35% 生命：蓄力一次定向招式，展示方向和落点；光环可以打断，侧移/冲刺也可避开。

标准预警从至少 1.0 秒起调，长夜至少 0.8 秒；配合形状、明暗与音效提示。首轮保留 500 生命，用招式和场地测试应对价值，再根据结果调参。阶段跨越和快速击杀都要正确结算，不能因动画或阶段切换卡住出口。

**首轮实验值，均为待验证候选：**

| 参数 | 当前 | R1 候选 | 检查方式 |
| --- | --- | --- | --- |
| 灯塔恢复 | 全时 12 生命/秒 | 漫游维持；标准战斗中 3、长夜 2，脱战约 3 秒后恢复 12 | 同一敌人/装备对照站桩、走位与恢复窗口 |
| 常规巡逻资源 | 随持续刷怪累积 | 三章星砂预算 40/55/70、经验预算 80/110/140；标准与长夜相同 | 连续驻灯两段 120 秒，预算耗尽后不再增加常规刷取收益 |

| 锻造费用 | 12 / 22 | 12 / 24 | 第一笔投入可达，后续投入需与购装/补给取舍 |

巡逻预算与锻造数值分开做对照，再测组合，防止同时收紧收入和收益而误伤新档。若恢复空间不足或主线资源短缺，先回调预算/恢复，再增加其他压力。

### R2：每局做出不同的行装与路线选择

先改现有 12 件装备的作用和三套装机制，让现有收藏有更多用途。

| 流派 | 三件套候选机制 | 主要优势与取舍 |
| --- | --- | --- |
| 远行邮差 | 冲刺穿过火种触发短时顺风；有独立触发间隔 | 赶路、收集、投递更顺畅，持续正面输出较少 |
| 守灯人 | 光环展开短时护灯屏障，可抵挡一次攻击；与技能周期绑定 | 保护点灯和危险交互，依靠时机取得生存优势 |
| 曙光回声 | 光环施加余晖标记，后续光弹触发一次范围回响；设置内置间隔 | 擅长处理敌群，需管理距离与光环窗口 |

将强化池从 5 项扩至 12 项，新增方向覆盖冲刺、投递、护盾、光环标记与单目标输出。选项展示真实变化、触发条件和叠加上限。三选一按类别约束抽取，保留生存/移动/输出的选择机会；不保证每次都给到同一最优项。

第一章第二盏灯增加一次简短构筑选择，连同两次跨章强化共三次。新增选择状态与换章状态分别处理；保存当前已抽出的选项和领取标志，恢复后不重抽、不重复领取、不误触发换章。

额外构筑选择采用独立生命周期：点灯完成 → 进入选择并暂停模拟 → 领取一次 → 留在本章继续；只有到达章末出口才进入原有换章流程。

每章准备三套连通的手工模板，共九套；保留三章主题、出口方向和可识别地标。每章提供主路与一条可选风险支路，支路给予精英、事件或行装选择。首次旅途使用易辨识模板，后续按种子组合。地图、战斗与掉落使用分开的随机流，使同一挑战种子的布局不会被此前杀敌次数改变。

新增两种行为清晰的敌人：有方向预警的远程投影者、需要优先处理或绕开的护灯结界者。控制同屏数量，避免多个新机制同时覆盖手机上的玩家和技能键；相应敌弹与掩体交互要有一致的视觉说明。

### R3：给下一局明确目标

- **故事旅途**延续已购课程、藏品、信件与结局；后续成长以行装、故事和外观解锁为主。
- **公平挑战航线**使用统一课程、初始补给和指定藏品，保留日期种子与离线重试；奖励首次结算一次，重试用于练习与个人纪录。
- 提供四种明确展示的可选条件：浓雾、小包裹、加急投递、精英巡夜。每种对限制、奖励和影响的主线目标作说明，并有可完成性检查。
- 新增八项围绕三流派、风险支路与挑战条件的成就。奖励以收藏和故事为主，避免挑战难度被重复堆高的永久数值抵消。
- 结算展示所选流派、主要资源收入/支出、受击来源、委托进度和一次可尝试的下一局目标。背包提供换装后的属性与机制比较。

四种条件的首轮定义如下。开始前展示完整规则和奖励，每个条件都需覆盖主线及三种结局的资源可达性。

| 条件 | 玩法变化 | 保留的完成保障 |
| --- | --- | --- |
| 浓雾 | 缩小远处细节与敌人可见范围 | 近身预警、灯塔方向与交互提示保持清楚；必须用真实渲染与操作验证 |
| 小包裹 | 火种携带上限候选为 8，要求规划收集和支付顺序 | 单座灯塔仍需 4 火种，分享与事件可分次准备资源 |
| 加急投递 | 候选 180 秒为额外奖励目标，记录个人最好成绩 | 超时仍可完成旅途；阅读剧情与选择菜单暂停计时，重复刷取奖励无效 |
| 精英巡夜 | 用预告清楚的精英组合替换部分常规巡逻 | 控制同屏数量，预算内奖励不随等待时间增长 |

八项新成就分别围绕：远行套完成投递、守灯套抵挡危险、曙光套触发回响、混搭通关、完成风险支路、统一预设挑战首胜、小包裹送达、加急奖励。具体门槛在对应机制落地后确定，不以重复驻灯时长作为目标。

## 4. 平衡验收

| 维度 | 验收内容 |
| --- | --- |
| 主线可达 | 新档在三档难度均可完成主路；点灯、分享与事件的资源组合可达。付费选择失败原子回退 |
| 反无限刷取 | 常规资源有可验证上限；预算耗尽后的额外驻留不再增加常规星砂/经验/计分；读档不能恢复预算 |
| 主动应对 | 在同装备同种子的站桩与预警应对策略间建立配对对照。标准/长夜至少有一种可用换位或技能规避的清晰威胁；应对策略在受击、危险时间或补给消耗上有可重复的改善。通关、死亡与超时分别报告，不为制造比例差异强行提高伤害 |
| 构筑可行 | 三流派和至少一种混搭完成固定种子矩阵。检查时间、生存和资源三项，排查同时占优的无成本组合；不以单一 DPS 排序代替体验判断 |
| 难度区分 | 对照同配置的受击、低血量时长、技能使用和资源消耗；长夜常规资源总量不高于标准，保留挑战积分价值 |
| 地图与追击 | 轻量可达性检查覆盖 1000 个布局种子；复核本轮 1002/1004/1005/1009 等停滞候选；主动策略不得因纯寻路僵持跑到 1200 秒上限 |
| 规则准确 | 选项文字与实际属性、回血、额外目标、冷却和套装触发一致；重算、换装、切后台不会重发收益 |
| 移动端 | Android 模拟器的横竖屏、双指移动+技能、模态滚动、返回、后台恢复与进程重建；实体手机反馈单独列示证据 |

基础自动对照先沿用 20 种子 × 3 难度 × 2 档成长 × 3 路线。新增招式后，先补能识别预警的对照策略，再评估策略差异；旧机器人不会新招式所导致的失败不能当作平衡改善。

记录战斗中的最低血量、低血量时长、实际受击、净恢复、首领阶段与资源流向；结算满血和机器人通关比例只作为辅助信息。观察性目标与硬性正确性门禁分别记录。

## 5. 存档、性能与双端发布

新增运行字段通过版本化迁移补齐。旧运行保留地图、生命、装备、资源与已抽选项；旧规则使用明确配置继续该局，新规则在新旅途启用。新增独立的规则版本标记，使奖励预算、护盾和首领阶段不会在旧运行中途突然生效。永久课程、已获成就、信件和收藏保留，奖励账本继续幂等。验证 schema 1/2 的旧档迁移和运行中读档。

公平挑战的日期、规则版本、条件和初始配置一并保存；局内不读取后来购买的课程。首次奖励使用持久化唯一记录，重复结算、读档和当天重试均不重复发放。规则升级时明确分开个人纪录，避免不同规则的用时直接比较。

新增场景、敌人和套装仍由原有矢量/Canvas 与合成音效表达。给敌人、投射物和特效设上限，路径查找有每帧预算；同环境同场景下比较 v1.1.1 的模拟耗时与内存，不以界面暂停掩盖运行开销。

发布沿用现有公开站点、Android 包名和签名；统一包版本、核心版本、界面、服务缓存与 APK versionCode。当前 `core.VERSION` 仍为 1.1.0，需在下一次运行时升级时一并纳入版本一致性检查。新资源加入离线壳。旧标签页安全切换，同一份已核验 dist/ 生成网页与 APK，发布前对照签名、资源哈希、存档和实际操作证据。
