## 机制核验

- 三武器/四被动槽位、五级上限、各武器对应进化、满构筑后的继续成长。
- 多个升级连续兑现，每次消耗一个待领取机会，不满血、不跨层；重抽有持久化次数。
- 清场奖励与吸取未拾经验只领取一次；付费休整、清场商店与库存原子扣除，读档后不复购。
- 三首领锁定预警与打断；落雷先警告后伤害，移出圈外免伤。
- 灯塔有限回复、没有站灯被动回血或驱敌；一次复起用后不能通过读档恢复。
- 无尽层数不会在第三章结束；第六层以后仍能推进。无尽封存独立记录，不解锁剧情结局或增加剧情胜场；邮票结算幂等。
- 非法等级、第四武器、未知卡牌、过大待领队列和异常落雷状态会拒绝恢复。原 schema 1/2 与 schema 3 剧情存档回归成功。

## 解读限制

机器人知道全图位置，反应快于人类。15 层主动测试用于检查构筑、推进、首领与存档，不作为玩家胜率或难度已充分平衡的证据。探索性深层测试中出现更高伤害、死亡和较长首领战；真实玩家的可读性、手感、长期留存与厂商手机耗电仍需要游玩反馈。
