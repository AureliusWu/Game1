# v1.1.0「暮色百事」验证记录

验证日期：2026-11-06（北京时间）。

## 自动化结果

73 项自动化测试全部通过，涵盖原有 36 项规则/通关/离线测试、30 项系统测试、7 项扩展通关测试。

扩展完整流程机器人只走实际路线并使用真实功能：采集火种、选择居民对话、开箱穿戴、商店支付、奇遇与精英战、锻造、灯塔投递、选择强化、击败守夜者、通过最终门。测试中途序列化并恢复存档；不传送、不改生命来跳过战斗。

额外运行三档难度 × 两种对话路线 × 十个种子，共 60 段扩展旅途，全部正常通关，分别得到「回信成河」或「人间灯火」；最慢 97 秒模拟时间。最短路线机器人不能代表首次人类玩家的阅读与探索时间。旧有直接通关路线保持可达，结局为「黎明签收」。

## 重点契约

- 装备属性即时生效，二/三件套正确组合；反复重算和换装不叠加、不白送生命。
- 锻造正确扣费并封顶，余额不足不改变状态；穿戴与基础行装不可拆解；重复装备兑换星砂。
- 交易检查距离、库存、资金、已持有装备、满血与补给上限。
- 居民选择消耗实际火种；投递仅在亮灯范围内完成，一次发奖；信任和三封信影响最终结局。
- 奇遇资金/生命条件完整；精英战利品必须在真实击败后发放。
- 成就、单局结算、委托、每日首次奖励在重复调用和元存档恢复后均不重复发奖。
- 永久课程真实扣除邮票、封顶三级，使用启程快照；启程藏品限制为已发现的非基础装备。
- schema 1 旧运行迁移为 schema 2，原地图、强化、火种与生命保留。
- 离线预缓存包含所有新模块；子目录部署、带查询参数访问和缓存更新测试通过。
