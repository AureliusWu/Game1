# v1.0.0 验证记录

验证日期：2026-11-06（北京时间）。

自动化测试：36 项全部通过；静态包检查通过，运行时合计约 142 KiB。

## 规则与流程

- 核心测试覆盖：种子确定性、非法难度、移动归一化、冲刺穿墙、边界、火种拾取、费用扣除、点灯、生命恢复、光环冷却、自动瞄准、暂停、门的开闭、强化、首领解锁、胜负结算与存档。
- 完整旅途测试：三档难度 × 三个固定种子，从真实采集、点灯、战斗与强化到最终拱门，全程不传送、不跳过敌人、不更改生命来通过测试。
- 补充模拟：三档难度 × 二十个种子，共 60 轮正常通关；最慢 78 秒模拟时间。机器人使用已知地图最短路径，不能代表初次人类玩家用时。
- 100 个种子的首领出生碰撞回归通过。修复了原先大体型首领可能被小体型出生边界卡住的问题；测试使用首领完整碰撞半径。
- 损坏、缺字段及不兼容存档在进入渲染器前被拒绝。

## 浏览器操作

使用 Chromium 实际操作，检查了：

- 桌面 1366 像素级主菜单、原创插画、游戏场景、HUD、小地图、目标指引与技能按钮。
- 键盘移动与拾取，光环和冲刺的冷却反馈，暂停与继续。
- 保存退出后刷新，再从「继续上次旅途」恢复世界与技能冷却。
- 手机 390 × 844 CSS 像素的实际嵌入视口；画面宽度、滚动宽度均为 390，无横向溢出；触屏摇杆与双技能可操作。
- 玩法手册、设置、摇杆开关、弹窗和返回菜单。
- 浏览器控制扩展有自身日志噪声，未据此归因于游戏。

手机验证使用浏览器中的窄视口，并非实体 Android / iOS 设备。音频为浏览器 Web Audio 合成，需首次用户交互才能开始；静音不影响游戏运行。

## 离线与发布完整性

静态检查校验 JS 语法、HTML ID 唯一性、UI 引用、图标、manifest 与离线资源清单；运行时无外部依赖或网络 API。离线壳必须在首次成功加载后完成缓存，浏览器清理缓存或受限存储环境可能使其失效。

真实设备的断网安装与长时间电量表现，未在本环境中实测。私有在线预览的身份验证由托管服务负责；离线游戏不依赖实时账号请求。
