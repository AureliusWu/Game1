# v1.4.0 · 疾焰连击

让每次冲刺和清怪都有更直接的回报。

- 冲刺切伤沿途敌人，光环清除范围内敌弹。每次冲刺对同一敌人只命中一次，障碍与出生预警继续有效。
- 普通击杀积蓄 10 点破晓能量；满 100 自动进入 6 秒超载，刷新冲刺/光环、攻击节奏加快 65%，释放近身震荡。爆发期间停止蓄能。
- 更紧凑的敌潮、更清楚的命中亮色与描边、冲刺光痕、合并伤害数字和分层击杀音效。降低动态效果设置继续有效。
- 无伤清场额外 +6 星砂，路线页显示本层用时；强化卡显示基础效果并突出立即进化的选择。
- 修复慢速敌人绕障碍反复折返导致清场停滞，以及高等级急件封蜡受基础射速下限限制的问题。
- 旧版未完成无尽旅途继续使用原规则，剧情、成就、装备与存储键保持。同签名覆盖安装保留 Android 数据。

模拟实验用于规则与节奏比较；真实玩家手感仍需游玩反馈。
