# 余烬信使 v1.8.2 · 夜潮不息

## 战斗体验

- **无尽层间无弹窗**：清场后自动领取本层技能、奇物及夜航刻印奖励，按随机路线直接进入下一层；不会每层重复弹出「选择强化」和「下一层路线」。战斗中积累经验升级仍保留四秒三选一；玩家不点会自动选。
- 已有 v1.8.x 无尽存档续玩时自动启用无缝层间，保留当前已经打开的选卡；v1.7 及更早无尽存档沿用旧规则以保证历史重放一致。
- **反站桩**：玩家连续约三秒几乎不移动，就会出现 1.25 秒预警的追踪落雷，移动可躲避。连续停留会再次受威胁。该机制仅在新版无尽流程生效。
- **敌群强化**：从首层就可生成高速扑击怪和远程弹幕怪；第三层起加入狙击，后续继续增加壁垒者。新版敌人生命 +60%、移速 +25%、伤害 +25%，刷新更频繁。清场恢复生命降为 5%。
- 限制旧存档受影响范围：只有显式的无缝流程标记启用新版平衡，日常挑战与剧情继续沿用原设定。

## 手机横屏 UI

- 右侧短时选卡使用独立行布局，每项固定高度、完整的图标+名称+一行说明，选卡与页脚有清晰分隔，超长说明省略但可查看按钮提示，不再叠压底部按钮。
- 战斗提示移至底部小条，避免遮住屏幕中央的猫头鹰主角、敌人及射弹。
- 右侧下方的光环、冲刺、补给按钮继续可用。
