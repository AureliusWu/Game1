# v1.10.0 · 重击回响

本轮加强命中重量、受击回弹、移动轨迹和击杀反馈，保留 v1.9.4 的换层停帧修复与异常恢复。

- **打击顿帧**：重击约 24ms、冲刺连斩 26–42ms、精英击破 42ms、首领击破 58ms。普通命中和单只普通敌人死亡不触发顿帧。暴击仅使用 14ms 的轻顿帧；同批命中合并，强反馈可以替换弱反馈，不能按敌人数无限叠加。每次最多 58ms，另设 75ms 容量、每秒补充 100ms 的预算和 180ms 触发间隔，限制持续战斗中的停顿密度。
- **方向性受击回弹**：命中时沿来袭方向压缩、轻微视觉后移，再衰减回弹；首领变形更克制。反馈只改变绘制，不移动碰撞体、不改变伤害或敌人招式。
- **真实路径残影**：冲刺残影采样实际位置，带渐隐光轨，最多 8 个采样；子弹拖尾按速度延长。换层清除轨迹，避免把上一层残影带进新地图。
- **击杀与数字**：按武器色加入局部消散圆环，精英／首领反馈更大；暴击和重击数字短暂放大并加深色描边；重击和精英击破音效补充短促低音。保留伤害数字合并、连杀提示与现有击杀奖励。
- **柔和动态与开关**：旅途设置新增「打击顿帧」。关闭后立即恢复完整时间推进；「柔和动态」自动禁用顿帧并收起残影、受击变形与震屏，保留原顿帧偏好，方便之后恢复。

顿帧属于界面运行时状态，不写入存档，不改变规则、伤害、成长、敌人预算或碰撞。游戏与实时选卡共用扣除顿帧后的时间，后台、手动暂停、选卡暂缓和竖屏门禁清除待执行顿帧；不会积攒需要补跑的时间。普通层自动领奖与前进、首领手动选择、存档 schema 3、全部存储键和签名身份保留。

## 验证与发布门禁

- 新增 10 项行为回归：30／60／120 Hz 持续密集命中的预算上界与恢复、普通命中不顿帧、同批强反馈合并、禁用与重置、回弹有界且回归原形、特效池上限，以及实际 UI 循环的无追帧、选卡／战斗时间一致性和暂停门禁。
- 本地检查 246 项测试与静态／离线／版本一致性；使用正常战斗产生的冲刺命中状态实际执行 Canvas 绘制检查。旧版兼容回放继续由现有测试验证。
- Android 新增第 8 个真 WebView 用例：观察实际命中产生的顿帧、受击变形与冲刺残影；通过正常控件关闭顿帧并验证时间继续推进、设置持久化、柔和动态覆盖及特效池上限。原有 7 个用例和全部断言、双横屏截图、连续换层验收保持。
- 沿用公共 CI、Android 编译／设备验收、实际 Windows EXE 验收、签名与三端资源一致性检查；全部成功后才发布 APK、EXE、网页 ZIP 和 Pages。

运行时新增 `feedback.mjs` 并加入离线预缓存。源码、界面、Windows 包与缓存版本统一为 1.10.0。正式下载及设备验收状态以对应 GitHub Actions 和 Release 为准；新版 APK 支持同签名覆盖安装保留进度。
