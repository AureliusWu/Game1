# 余烬信使 v1.9.0 · 破风回响

## 可玩性：主动冲刺带来真实收益
- 新开的无尽局（`endless.flow.version=1`）连续冲刺命中四名敌人（可跨冲刺，5 秒内连上）触发「破风觉醒」：**4 秒全部攻击与武器伤害 +25%**，光环冷却减少 1.8 秒、冲刺冷却减少 0.6 秒。
- 正面受到伤害将打断连斩蓄力和短暂伤害增益。既有无尽档没有 `flow` 对象，完全沿用原机制。
- 破风只由真实冲刺路径命中驱动；站桩自动射击不能直接触发。每次冲刺对同一敌人仍只结算一次伤害，不增加无预算敌人或奖励。

## 战斗爽快感
- 普通、暴击、重击分别显示不同的命中圆弧和冲击线；冲刺命中与精英/首领击破追加短促震屏和粒子。
- 破风积攒与爆发使用全新合成音效；命中音高随暴击反馈变化，保持 48 声部上限。
- 战斗特效以低动态设置为准降级，粒子/反馈均有数量上限，不额外引入图片、音频依赖。

## 手机横屏与 HUD
- 减少任务与状态栏文字长度，新增小型破风指示，清楚展示冲刺命中进度和爆发剩余时间。
- 临时提示移到左侧中段，避开中央烛羽与右下角技能按钮；选卡期间隐藏临时提示。
- 保留 v1.8.2 横屏选卡压缩布局、自动进层、离线运行和旧存档路径。

验证：Node 单元测试、静态检查、Android 双向横屏和离线回归、Windows EXE 启动验证。
