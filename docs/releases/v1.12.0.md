# v1.12.0 · 长夜入画

怪物和场景原画进入实际战斗；本轮同时检阅角色、武器、技能、物品、居民与菜单，统一为烛羽现有的手绘童话风格。

- **8 类普通怪、5 种首领**都有独立图片与轮廓；出生预警、受击变亮 / 回弹、冻结、精英标志和首领阶段提示保留。
- **7 张无尽地图与三章剧情场景**接入不同的石街、雨巷、庭院、运河、铜砖与屋脊材质，配合石屋、花房、钟舍和植物装饰。建筑底部对应原障碍范围，屋顶在角色经过后方时变淡。
- 灯塔、商店、开 / 闭箱、井、古钟、邮箱、风险旗和出口门接入原画；三个居民在场景和对话中共用对应角色图片。
- 12 件装备、8 项被动、8 件奇物分别接入图片，覆盖背包、装备栏、商店、收藏、图鉴、选卡与构筑页。
- 重绘主菜单石桥插画；保留三套皮肤、四件武器原画、笔触特效和移动选卡输入。

新增 74 个图块、10 张 WebP，合计约 4.00 MiB；完整 53 项静态资源约 5.30 MiB。共享预载、明确裁切、保留透明与缺图回退，全部进入三端离线包。地图、战斗、随机流、旧档、包名与签名身份不变。

本地 **258 项测试**、静态 / 离线 / 版本检查通过；保留全部历史重放与原 9 个 Android 仪器用例，增加离线贴图 / 战斗绘制 / 背包 / 图鉴验收。发布继续以 Android 模拟器和实际 Windows 免安装 EXE 全部门禁为前提。
