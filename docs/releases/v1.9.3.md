# v1.9.3 · 旅途续存

修复无尽第三层起遇见既有新敌人后无法恢复存档的问题。敌人实例校验已经支持破阵者、远望者和重装结界，但旅途的 `encountered` 白名单遗漏了这三种类型，导致合法存档被拒绝。本版补齐已有类型，未知类型仍然拒绝。

保留 v1.9.2 的 Flow Burst、当前横屏 HUD、普通层自动领奖与前进、首领手动选择和反站桩机制。保持存档 schema 3、原存储键、角色与三章剧情身份，不加入旧 PR 的暂停直接结算或额外早期抽卡。

Android 验收保留原有六个用例和全部原始断言：真实战斗赚足星图购买预算，校验两节点购买与完整退款；在同一 JavaScript 任务里捕获退出前选项，验证退出和恢复均未替换选项；补充抽卡身份、旅程、计时与可继续状态校验。真实模拟器、双横屏截图、离线启动和存档恢复仍由既有 CI 执行。

新增回归覆盖真实击杀与升级、普通层和第五层首领奖励、第三层及之后的保存恢复、旧存档兼容、暂停计时、非法选择原子拒绝，以及未知敌人类型拒绝。既有主线测试、工作流、超时、截图规则与测试选择器保持不变。

源码版本、界面版本、Windows 包版本和离线缓存同步为 1.9.3。正式下载与发布状态以 GitHub Release 为准；PR 验证不会签名、发布或部署。
