# 余烬信使 v1.8.0 · 夜航焕新

## 手机横屏战斗 UI
- 根据实际横屏截图重新排布角色生命、经验/破晓蓄能、构筑、击杀/武器、中央清场目标和状态；缩短文字、控制提示宽度。剧情来信移至偏左中侧，避免遮挡 HUD 和摇杆。
- 技能选卡改为**右侧紧凑三张卡**，保留左侧摇杆、右下技能按钮、战场与角色可见。支持键盘、触屏移动/冲刺/光环。
- v1.8 新开无尽局在技能选卡期间**实时战斗**，4 秒自动选合法卡；层间路线 6 秒自动走普通路线。主动暂缓或切到后台时停止计时与模拟。新手选择时可能被攻击，务必及时应对；旧无尽存档维持冻结选卡，旧的倒计时合法继续。
- 实时选卡的身份用序列号固定，战斗中升级 XP 即使产生额外 pending，也不会刷新选卡计时；死亡会正常结束。

## 七张随机地图
残钟广场、雨巷折廊、风口回廊、荧石庭院、沉灯运河、星屑长街、雾钟屋脊：不同障碍、灯塔位置和背景色系。随机种子决定布局，**相邻关卡绝不会重复**；提供地图路径可通行性回归测试。

## 更多敌群与流派
- 新增突击者（高速预警扑击）、远望者（远程扇形弹幕）、壁垒者（大范围震荡环）。8 层后精英增多，精英词缀扩为五种（新增震爆与追光）。
- 首领从三组招式扩展为五组，保持预警、打断及半血狂暴机制。
- 夜航刻印从三条扩为五条：新增寒潮（光环附加范围冰伤与减速，联动霜降邮戳）与守望（光环屏障，联动长明灯芯恢复）。每隔三层刻印奖励三选一，已拥有的刻印有成长优先权。
- 故事模式与公平挑战的敌群及关卡规则不改变。

验证：`node --test tests/*.test.mjs`、`node scripts/check.mjs`，以及网页 / Android / Windows CI 工作流。

兼容说明：没有 `endless.draftSerial` 的旧局严格保留原三地图几何、随机数与 floor 事件结构，避免改变历史回放、碰撞与存档断点。
