# v1.6.0 · 星图来信

烛羽开始有了自己的成长方向，送达的信也开始有后来的故事。

- **夜航星图**：远行之翼、守灯之心、破晓之光三条路线，共 15 个星点。前置解锁、分级价格、三种终点技能；可自由混搭，免费全额重置。旧邮局五门课程保留，也可全额重置。购买和重配在下次启程生效。
- **长期养成**：战斗、点灯、送信积累信使熟练度；8 项成长目标提供一次性邮票奖励。目标显示当前进度，重复打开、恢复和结算不重发奖励。
- **局内专精**：等级 3 / 5 / 8 各获 1 点，可分配疾行、守灯、破晓，累计三点激活主动技能联动。在无尽构筑或剧情背包内分配，即时生效；生命上限提升不会回复当前生命。
- **构筑主动权**：无尽每局两次放逐，移除一张尚未拥有的强化并补齐本次选牌，本局不再出现。放逐菜单暂停倒计时，取消不扣次数。构筑页显示起手武器的进化目标、伙伴缺口和放逐记录。
- **居民后续**：小朔、苔生、岑灯各增加两个后续分支。送达本章信件、点亮本章三灯，再回访居民；每个选择提供明确的本局效果，付费选项消耗真实星砂。前章的投递与分享会改变后续对话，结局增加与选择对应的后日谈，六条回音可永久收藏。

## 兼容与安装

保留包名、签名、三章主题、三种结局与全部存储键。旧运行沿用原成长规则；新星图和专精在新开的普通旅途启用。公平每日航线继续统一零成长起点，不带入技能树或新专精。

本次 Android versionCode 为 **10600**。同包名同签名覆盖安装保留数据。网页与 Android 各自保存进度。网页离线缓存更新需关闭游戏的全部旧标签再重新打开。
