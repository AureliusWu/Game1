# v1.8.1 · 安全自动更新与覆盖升级

- Web/PWA：后台检查并完整预缓存新版本；只在邮局菜单且没有弹窗时激活与重载，保留所有 localStorage 存档。多标签页不强制抢占旧缓存。
- Android：由原生主线程控制更新提示，下载 HTTPS 官方 Release，核验 SHA256 和已有官方签名证书后交给 Android 系统安装器；**系统确认不可绕过**。相同 package ID 和签名覆盖安装，保留应用数据。离线游戏本身依然完全本地执行；原生更新通道独立于 WebView。
- Windows：后台读取官方 Release 信息，确认后下载到应用数据目录，做哈希校验，在原可执行文件退出后原位置替换并重新启动；遇到写入限制不覆盖原程序，保留已下载文件供手动安装。
- 三端共用 v1.8.1 版本号和签名/哈希约束，不触碰旧存档键；更新前自动保存。历史 Release 仍不可变更。
