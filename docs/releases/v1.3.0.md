# v1.3.0 · 无尽夜航

把余烬信使的主入口改为无尽肉鸽。清开一层敌潮、拾光升级、选择强化，再决定下一条路；每五层必须面对首领，可以继续深入，也可以在清场后封存并结算。

- 四件起始武器：爆焰行灯、霜降邮戳、回旋护羽、连锁雷笺。八种被动，各五级；最多 3 武器 / 4 被动。武器五级配合对应二级被动，自动进化为不灭凤凰、永冬回信、千羽风暴或万象雷网。
- 八件奇物改变本局规则，包括玻璃灯心的高伤低血、光环触雷、冲刺冷却、连击狂热与一次复起。
- 狩猎、精英、奇物、补给和烬潮路线，三选一继续。清场驿站可购买热茶、补给或重抽；每项每层限购一次。
- 三种首领招式：锁定光束、冲锋与环形弹雨；带预警，可以移动躲避或用光环打断。雷雨、疾风和烬雪让不同楼层发生变化。
- 无尽灯塔改为一次性恢复，消耗 5 火种回复 20% 生命，不再产生可持续回血的安全区。敌潮和掉落按房间记账；只有清场才会继续下一层。
- 快捷键 1/2/3 选卡，J 查看构筑与进化条件。伤害数字、羽刃、冰环、雷链、火径和进化音效均为原创程序表现。
- 选卡、待领取经验、路线、奇物、重抽与商店库存一同存档。旧版剧情旅途、三种结局、课程、装备和存储键保留。网页与 APK 各自保存，同签名覆盖安装保留 Android 进度。

验证：125 项测试通过，144 次实际操作策略模拟完成，无超时样本。模拟知道地图并快速选择强化，不能据此推算真实玩家胜率或游玩时长。Android 离线、双指、横竖屏和选卡恢复由发行流水线验收。
