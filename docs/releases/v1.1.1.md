# 余烬信使 v1.1.1 · 网页与 Android

- 网页版公开发布：[立即游玩](https://ember-courier-game1.dazzlingmodel.chatgpt.site)。
- 首次发布 Android APK，包含完整三章、三种结局和「暮色百事」全部系统。
- APK 内置所有游戏资源，首次启动即可离线游玩；无需登录或联网权限。
- 原创猫头鹰图标、全屏、横竖屏切换、返回键、后台暂停与自动保存。
- 网页和 APK 使用相同游戏逻辑与存档格式；Android 安装更新保留本机进度。网页与 APK 分别保存，不自动跨端同步。

## 下载

Android 8.0 及以上下载 `Ember-Courier-v1.1.1.apk` 安装。系统 WebView 需要支持现代 ES 模块，建议保持更新。安装包为项目专用密钥签名的正式构建。

`Ember-Courier-web-v1.1.1.zip` 是可独立托管的完整网页成品；解压后使用 HTTP(S) 服务打开。`SHA256SUMS.txt` 用于核验下载完整性，provenance JSON 记录源码提交、签名指纹和内置资源哈希。

不含广告、付费内购、分析埋点、外部素材或在线服务。APK 不申请网络、文件访问、定位等权限。

## 验证范围

发行工作流必须先通过游戏规则与完整通关测试、静态资源检查和 Android 35 模拟器中的离线启动/保存/返回操作验证，再签名并发布。发布脚本核验正式 APK 非 debuggable、签名有效、包名/版本正确，且所有内置文件逐字节等同于网页资源。

模拟器验证不等同于实体手机长期测试；不同厂商的省电、音频、触屏和安装提示仍可能有差异。
