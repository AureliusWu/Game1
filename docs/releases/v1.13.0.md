# v1.13.0 · 动态夜行

聚焦已接入的手绘角色与怪物的战斗动态，不扩大核心玩法范围。

- 烛羽与敌人按实际位移呈现轻量步态、前倾和形变；冲刺拉伸、敌方蓄势压缩轮廓。
- 动作全部来自纯展示层 MotionTracker，不使用随机数或墙钟，不修改命中框、地图、伤害、奖励、BOSS 逻辑或存档。
- 换层、瞬移、柔和动态立即重置动作；旧版画、危险提示、原有回弹与图像缺失回退保留。
- Web / Android / Windows 同步 v1.13.0，PWA 离线缓存新增 motion.mjs。
- 8 项动作回归测试；发布前还需原规则测试、原生 Android 模拟器与 Windows EXE、Pages 统一门禁。

限制：本轮为程序化贴图动作，不含逐帧动画或物理手机性能验收。下一步以真实设备的游玩反馈再调整敌潮难度。
