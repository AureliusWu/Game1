# v1.7.0 · 横屏启航

- Android 原生固定横屏，支持左右两种横持方向。网页 PWA 声明横屏；浏览器允许时尝试全屏与方向锁，竖屏则显示横置提示，冻结旅途与自动选卡倒计时，恢复横屏后继续原状态。
- GitHub Pages 成为主要网页发布渠道，main 的网页变更通过 Actions 自动部署。部署后实测 HTTPS、JavaScript MIME 与全部 29 个公开资源的 SHA-256，确保 `/Game1/` 子目录可以载入。
- 新增 Windows x64 免安装 EXE，内置完整离线游戏，F11 / Alt+Enter 全屏，关闭前保存、失焦暂停。当前没有 Windows 代码签名。
- 统一 CI：公共测试只运行一次；按变更选择 Android / Windows 并行任务；缓存 Gradle、Android 系统镜像、npm、Electron 和打包工具；PR 取消过期运行，main 发布保持串行。
- 网页 ZIP、原签名 APK、EXE 共用一份经过验证的网页资源。APK 验签、Android 实机模拟测试、EXE 真实启动与 ASAR 哈希核对通过后，交叉检查三端资源再创建不可覆盖的 GitHub Release。
- Actions 手动入口 `Game CI and releases` 可选择 all / web / android / windows / check，并可关闭 publish 只构建验收。

保留 v1.6.1 的技能树、六条剧情后续分支、局外熟练度和局内专精 / 放逐，以及全部既有玩法和存档键。Android 版本号 10700，保持原包名与证书，可覆盖安装。GitHub Pages 与之前网页地址属于不同来源，各自保存网页进度；Android 升级继续原有存档，Windows 保存于用户数据目录。

最终运行与发布证据写入 `v1.7.0-verification.json`，只有实际通过后记录结果。

发布验收完成：188 项公共测试、Android 6/6、真实 EXE 测试、Pages 29 项线上资源与公开附件校验通过。完整记录见 [QA_v1.7.0](../QA_v1.7.0.md) 与 [verification](v1.7.0-verification.json)。
