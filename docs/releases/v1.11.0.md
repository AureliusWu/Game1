# v1.11.0 · 巡猎与远行衣橱

本轮围绕四个实机反馈调整：走位压力来自敌人，选卡保持输入，战斗加入原画贴图，烛羽拥有可保存的外观。

## 战斗与走位

- 移除现代无尽旅途的原地滞留雷击，包括旧存档已排队的追踪雷圈。雷雨也不再定期锁定玩家脚下。
- 新建旅途以 `endless.encounters.version=1` 启用混合敌群：第一层出现散射施法者，第二层加入突袭者，第四层加入狙击者，第六层加入重装。
- 近战按左右侧翼接近；远程敌人保持射程并横移。所有目标点仍经安全点和原有寻路处理。
- 狙击预警锁定后给出 1.15 秒侧移窗口，不追踪改向；实体遮挡可以挡下光束伤害。光环仍能打断招式。雷雨使远程敌人的蓄势散射增至五发。
- 新 AI 不追溯写入旧局。v1.3/v1.4/v1.5.1 真实兼容存档继续通过原有重放断言；存档 schema 3 和全部存储键不变。

## 无痕选卡

- 战斗强化使用三张紧凑图卡，靠右置于技能按键上方，保留 4 秒自动选择和原有推荐/费用/放逐逻辑。
- 开启及关闭实时面板不调用浏览器 dialog 的自动聚焦/恢复聚焦；点击卡片不清除按住的方向键、摇杆或目标。
- 首领、暂缓、后台、竖屏和其他模态弹层仍按原规则暂停。强化身份与剩余时间随存档保存。

## 图片与演出

- 三套完整透明烛羽外观：暮色信使、雨夜巡灯、烬火远行。扩展系统或设置进入「信使衣橱」，全部免费，仅改变外观，选择自动保存。
- 四件透明武器原画：爆焰行灯、霜降邮戳、回旋护羽、连锁雷笺，接入起手武器、强化卡、武器栏和战斗实体。
- 原创四格火焰烟尘/霜风/电弧/羽刃笔触贴图接入技能、火径、光弹与冲刺。地面效果位于角色与敌人下方，粉色危险预警位于上层。
- 贴图共享预载与解码；图片失败仍保留原代码绘制。全部 8 张 WebP 与新模块进入离线预缓存，并支持 Android/Windows/Web MIME。
- 原画由 OpenAI 图像生成，基于仓库原有猫头鹰形象，未引入外部角色、版权素材或音频。技术转换仅压缩与缩放，来源和运行时 SHA256 见 [资产记录](../art/v1.11-assets.json)。
