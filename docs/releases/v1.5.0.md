# v1.5.0 · 战场回响

- UI：底部三张紧凑选择卡，不遮住角色与大部分战场；增加驱影计数、武器栏和清晰的默认选项。
- 倒计时：强化/奇物 8 秒后按构筑自动选择，路线 12 秒后走免费常规航线。P / 暂缓可停表，后台暂停，剩余时间随存档恢复。战斗在选卡期间暂停。
- 击杀：连斩里程碑、精英击破提示、上扬音阶和飘字；真实连斩带来少量冷却与星砂回报。
- 敌人：扑击、震地、散射与可击破的结界；迅袭/震地/散射三种精英词缀。首领轮换三种招式，半血进入第二阶段；预警可躲避，光环可打断。
- 演出：行灯、霜印、羽刃与雷笺实体，不同武器光弹、冰环符文、电弧、火苗、羽刃拖尾和光环冲击效果。柔和动态继续有效。
- 新怪物规则用于新建无尽旅途；旧存档继续原战斗规则并使用新 UI。Android 同签名覆盖安装保留进度。
