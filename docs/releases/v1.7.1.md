# v1.7.1 · 手机横屏一屏主界面

## 用户可见变化

- 手机横屏（短视口）进入单页主界面：保留无尽/剧情模式、起始武器、难度、开局、续玩、系统入口与记录；不需要向下滚动。
- 暮色百事（行装、手札、星图、邮局、成就）和旅途说明移动到「扩展系统」二级面板。点击入口会先关闭启动面板，再打开现有的系统对话框。
- 剧情委托、每日航线和附加条件移动到独立的「委托与航线设置」面板。原有选择、存档与难度更新逻辑不变。
- 针对低高度 385px、350px 的手机横屏增加紧凑样式；350px 以下将插画让位给操作按钮。保留刘海/圆角安全区。
- 保留网页、PWA、Android 横屏、键盘/触屏、离线缓存和 Windows 版本兼容。

## 验收清单

- 在 844×390、740×360、640×320 等横屏尺寸检查：无需滚动即可找到「开始」「继续」「扩展系统」，模式/武器/难度完整可点；未保存时「继续」隐藏。
- 无尽与剧情切换后，剧情配置入口的显示正确；配置完毕可以关闭，设置持久保存。
- 扩展系统中五类入口点击后不会被双层模态遮挡；系统面板内部滚动与返回正常。
- 竖屏强制旋转门禁、战斗 HUD 和选卡倒计时保持原有行为。
- 运行 `npm test`、`npm run check`，以及 CI 的 Web / Android / Windows 构建；CI 结果以工作流状态为准。

没有新增外部依赖或外部资源。缓存命名及四端共享版本更新为 v1.7.1。

## 肉鸽第一轮：夜航刻印

新无尽局每清场第 3、6、9……层，依次处理正常强化、奇物奖励，再获得「夜航刻印」三选一；刻印可以升至三阶，满阶不会再出现。

- **焚烬**：每累计击败 6 / 4 / 2 名敌人触发一次区域爆炸，爆焰行灯 Lv.3 使其留下火径。
- **疾风**：冲刺释放羽风范围打击并削减 0.15 / 0.30 / 0.45 秒冲刺冷却；回旋护羽 Lv.3 将羽风伤害提高 35%。
- **雷鸣**：光环额外触发连锁雷，随阶级提高弹跳数与伤害；连锁雷笺 Lv.3 再多跳两次。
- **可见反馈**：技能卡、构筑详情、战斗状态栏均显示，获得刻印时提示。
- **兼容性**：老存档没有 `endless.oaths` 时不参与刻印选卡，也不会触发新战斗效果。剧情和公平每日航线完全不受影响。

新增刻印抽选、等级上限、存档恢复、战斗联动、异常数据保护和旧存档隔离测试。
