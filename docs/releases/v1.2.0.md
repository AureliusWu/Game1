# 余烬信使 v1.2.0 · 夜路有选择

让行装、路线和主动应对真正改变旅途。保留烛羽、三章九灯、三种结局与「暮色百事」全部系统。

- 三种套装玩法：远行邮差冲刺拾光触发顺风，守灯人用光环架起一次抵挡，曙光回声以光环标记、光弹触发范围回响。
- 强化从 5 项扩至 12 项，第一章第二盏灯后增加一次局内选择。与两次跨章选择合计三次，选项和领取状态可保存。
- 每章三种连通街区布局；旗帜标记的风险支路可挑战精英，击败后获得行装与星砂。
- 新增远程投影者与护灯结界者；首领加入预告压灯和可用光环打断的定向回声。
- 巡逻和奖励有限，标准与长夜的巡逻资源预算相同。战斗中灯塔恢复降低，脱战仍可休整；精确路径检查修复障碍拐角追击停滞。
- 公平每日航线使用统一课程、黄铜行灯和初始补给，可叠加浓雾、小包裹、加急投递与精英巡夜。同日同条件组合的首次奖励只结算一次，重试可刷新个人纪录。
- 成就从 20 项扩至 28 项；八项新成就收藏纪念回信。背包增加换装对比，结算增加资源流向、受击来源、构筑机制和下一局目标。
- 新运行使用 schema 3；schema 1/2 旧档自动迁移，原旅途继续使用旧规则，原存储键、课程、装备和来信保留。

发行门禁：102 项规则/通关/离线测试，840 次策略实验，1000 个布局种子，Android 35 模拟器离线开局、保存/返回、横竖屏、双指移动与技能、Activity 重开续玩，正式签名与 17 个网页/APK 资源一致性核对。

实验用于验证规则和比较策略，不估算真实玩家胜率。实体手机长期功耗和厂商差异仍需真实设备反馈。
