# 《余烬信使》设计说明 · v1.0.0

## 方向

短时、温暖、带一点紧张感的生存冒险。让玩家在 2–5 分钟内经历「黑暗 → 采集 → 点灯 → 有了归处 → 继续前进 → 黎明」。不同局使用不同火种分布、敌人出生位置与强化选项。成长只发生在单局内，不设置日常、付费或数值刷取。

## 世界与主角

长夜让城市的灯逐一熄灭。暮色邮局仍在工作。最后一位信使烛羽，是一只穿着浅青披羽、背着焦糖色邮包的猫头鹰。他送出的不止是信，也是让人继续等待的理由。

| 街区 | 叙事意象 | 找回的信 |
| --- | --- | --- |
| 沉灯街 | 家门与等待 | 小朔：奶奶每天仍会把门打开 |
| 雨眠庭 | 雨水与新芽 | 园丁：春天会来的 |
| 无晓钟楼 | 接棒与回信 | 前任信使：你也会收到回信 |

每片街区第一次点灯会展示一封不打断操作的短笺。通关后烛羽收到来自城市的回信：「谢谢你，我们一直在等你。」

## 核心循环

拾取金色火种 → 每 4 枚点亮一座灯塔 → 安全区回血并规划下一段路线 → 用自动光弹、冲刺与光环应对影兽 → 点亮三座后穿过归途拱门 → 选择强化并进入下一章。第三章全部点亮后出现守夜者，击败它再通过最后的门。

火种兼任任务资源与回复道具，灯塔兼任进度目标与空间控制工具。没有额外资源条、复杂装备菜单或精确瞄准需求。离开灯塔生命缓慢下降，推动玩家继续送信；回到灯塔可以喘息。

普通影兽、迅影、重影和守夜者有不同体型、速度、生命和攻击节奏。所有出生有预警并避开玩家与完整碰撞体，避免突然贴脸和卡边。

## 单局强化

五种强化池，每次随机提供三项：顺风之羽（移速与冲刺）、长明灯芯（生命上限）、日轮回响（光环范围与伤害）、双星邮戳（额外光弹）、拾光口袋（拾取范围与火种回复）。强化可叠加，跨章保留，重开清空。

## 视觉与声音

深青夜色、灰绿砖石、暖金灯火、暗紫影兽。菜单是一张程序绘制的月下石桥插画。画面由 Canvas 路径与原创 SVG 构成，地图底图按章缓存；场景不依赖图片 CDN。Web Audio 以五声音阶、正弦音与三角音构建原创氛围与反馈。音乐在用户首次交互后启动，可静音，切后台暂停。

## 设备与持久化

桌面键盘与手机多点指针输入共用同一模拟核心。支持横竖屏、DPR 上限、视口跟随、目标方向指引、小地图、低动态模式和手动摇杆开关。存档每 8 秒写入一次；暂停、离页和后台有额外检查点。损坏或不兼容存档退回新游戏入口。高分、通关数、累计点灯和最快送达仅在本地保存。

v1.0.0 不包含账号、跨设备同步、多玩家、排行榜服务器或原生 APK。PWA 提供移动设备的全屏与离线体验。
